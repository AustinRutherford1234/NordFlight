# F/A-18F model source

`source.glb` is the 1K-texture GLB download of **Boeing F/A-18F Super Hornet - Free** by **bohmerang**, downloaded from [Sketchfab](https://sketchfab.com/3d-models/boeing-fa-18f-super-hornet-free-447caa975f534554a83f70f0877b73fb).

Attribution is required, commercial use is prohibited, and adaptations must be distributed under the same license. The source GLB is unmodified. The creator's listing additionally says it is for personal use only. This license applies to this asset and its adaptations; it does not automatically license the rest of the project.

The downloaded GLB contains separate canopy, cockpit, gear-state and rail meshes, but its airframe is a single mesh and has no animation clips. The original Blender source was downloaded separately for inspection.

`rigged.glb` is a CC BY-NC-SA derivative generated by `scripts/fa18f/build_rig.py` from `source.glb`. It separates canopy, control surfaces, folding tips, wheels and doors. The gear now has independent upper struts, chrome lower pistons, drag braces, torque links, hydraulic hoses and collars. The lower skin has bounded gear-bay openings; main doors swing from the inner bay edges to clear the wheels. Wheel hubs retain the source geometry and textures. The preview and game share the visual kinematics in `src/aircraft/visual/hornet_gear.rs`.

These are reference-shaped visual mechanisms with estimated dimensions and motion, not manufacturer engineering kinematics. The dedicated physics implementation and wheel-contact geometry are documented in `docs/hornet/VALIDATION.md`. Moving-deck arresting-wire and catapult forces are now simulated; their parameters remain engineering estimates. Asset checks verify required nodes and account explicitly for the surface area removed by bay cutouts using `rig_metadata.json`.


Rebuild it using `/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python scripts/fa18f/build_rig.py`, then run `scripts/fa18f/validate_rig.py` with the same Blender options to verify node presence and neutral mesh area. Run `cargo run --example fa18f_asset_preview` to inspect the derivative in Bevy: O toggles the canopy, H the hook, W the folding wingtips, E poses the control surfaces, and G cycles the gear. Set `NORD_FA18F_CAPTURE=1` to write `/tmp/nord-fa18f-bevy.png` and exit automatically; add `NORD_FA18F_OPEN=1` to capture the open and folded pose. The preview is not flight, collision, cockpit, or performance validation. Bevy 0.18 reports that it ignores extra `TEXCOORD_2` and `TEXCOORD_3` attributes; the source materials reference the default texture coordinate set.

The current gear uses independently posed upper struts, chrome lower pistons, drag braces, torque links and hoses, retaining the source wheels. Main and nose wheel paths are visual estimates, not dimensioned engineering kinematics. Bay cutouts are now present in the lower skin. The preview and application share `hornet_gear.rs`; primitive mesh children must retain their authored transforms. `NORD_FA18F_SEQUENCE=1 NORD_FA18F_GEAR_POSE=0 NORD_FA18F_UNDERSIDE=1` captures both directions, holding each state during GPU readback.

Hook correction: the arresting hook is now extracted as whole disconnected source components and animated from its forward attachment; the duplicate generated hook has been removed. `world_parent` updates Blender matrices before reparenting so new fittings keep their authored orientation. Main tires tuck below the belly before lifting into the bay; a 1,001-position tire-envelope regression checks wall clearance.

The exhaust is generated in `src/aircraft/visual/hornet.rs`: shared tapered envelope and compression-cell meshes, a recessed radiant engine face, and independent local lights. The afterburner presentation follows the existing spool-based 0.88–1.0 power range; it does not add thrust or change the engine model. The unlit additive materials animate their base color directly because Bevy's unlit shader bypasses emissive lighting. Brightness, width, length and subtle bending use deterministic simulation time, preserving pause behavior and physics RNG independence. Local lighting and all visible layers shut down independently for failed engines. The effect is an artistic approximation; it does not simulate combustion. A colorless screen-space heat-haze shader now displaces the opaque background through a tapered, animated exhaust volume; it is a visual approximation rather than a computed temperature field.

For repeatable running-app captures, set `NORD_AIRCRAFT=fa18f NORD_FLEET_CAPTURE=exhaust-full` and launch with `--visual-check dry`. Other capture modes include `exhaust-idle-rear`, `exhaust-military`, `exhaust-partial`, `exhaust-full-night`, `exhaust-full-motion`, `exhaust-full-single`, and `exhaust-off`. Captures are validation presets, not additional flight controls. Brightness was compared in daylight and at night; see the Navy's [F/A-18 launch afterburner photograph](https://www.defense.gov/observe/photo-gallery/igphoto/2002023164/) for an operational visual reference.

Heat haze references: [U.S. Navy Hornet exhaust heat-wave photograph](https://www.dvidshub.net/image/9213900/afterburners-f-18c-hornet-bathe-flight-deck-heat-waves) and [NASA background-oriented schlieren explanation](https://www.nasa.gov/image-article/airborne-background-oriented-schlieren-imaging-airbos/). The shader is `assets/shaders/hornet_heat.wgsl`. It uses screen-space background sampling, soft opacity and simulation-time normal ripples, and stops independently with each engine. As a screen-space effect, it depends on visible background detail and cannot reconstruct off-screen objects.

Door correction: main leg panels now swing outward, and leg panels open with the bay-door phase before wheel travel. Wheel covers open to 95 degrees to clear the tuck path. Detached hinge knuckles on panel sections away from the hinge line and residual source gear-state fragments were removed. Bay rims and closed panels sit closer to the belly, with a revised exterior finish. `validate_rig.py` additionally rejects residual source gear meshes and hinge fittings outside their panel bounds. Close-up sequence captures are under `tests/fa18f-door-fix/`; the mechanisms remain estimated game geometry rather than manufacturer kinematics.

`escape_canopy.glb` is a CC BY-NC-SA derivative extracted from `rigged.glb` by `scripts/fa18f/export_escape_canopy.py` for the jettison animation. It retains bohmerang's attribution and the license above. The fitted tandem cockpit and code-native escape seats are described in `docs/hornet/COCKPIT_AND_ESCAPE.md`. The revised nose-well clearance and flat nose-tire stowage are estimated visual geometry; the original `source.glb` remains unchanged.

2026-10-30 gear/intake revision: the nose leg now swings forward/up about one transverse hinge; the tyres retain their axle direction. The deeper/longer nose well accepts the upright tyres. Main and nose door skins follow measured perimeter heights from the original hull/closed-state meshes, bow outward, reuse the source fleet-finish texture, and include connected hinge feet, inner ribs, fasteners, closure lands and sill-shaped wells. Shoulder AIM-120 stations now sit ahead of the main-door sweep; their shared station definition also drives mass properties and release origins. Recessed intake liners and F414-inspired fan cases, 36 twisted rotor blades per engine, spinners and stators replace internal blanking sheets. Each rotor follows its own modeled engine spool and freezes when paused; the visual rate and internal routing are estimates, not engine CAD or measured rotor RPM.

Additional authoring checks: `scripts/fa18f/validate_gear_sweep.py` checks generated tyre/door/well intersections and fuselage missile clearance; `scripts/fa18f/validate_intakes.py` checks that retained geometry does not hide the fans. `scripts/fa18f/intake_geometry.py` is executed by the main rig generator. The existing noncommercial/share-alike license continues to apply to the derivative and reused source finish.
