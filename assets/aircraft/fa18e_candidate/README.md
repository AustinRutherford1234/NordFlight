# F/A-18E candidate for evaluation

`source.glb` is the 1K-texture GLB download of **Boeing F/A-18E "Super Hornet"** by **KOG_THORNS**: https://sketchfab.com/3d-models/boeing-fa-18e-super-hornet-9e852037bf2141dcb3fda17013958131 . The listing identifies the license as Creative Commons Attribution 4.0: https://creativecommons.org/licenses/by/4.0/ . Credit KOG_THORNS and identify any changes when distributing derivatives.

Blender 5.2.3 imported the GLB successfully. It contains numerous separately named mesh nodes, including `Tailhook1`, `Tailhook2`, `Wf11`, and `Wf21`, but no imported animation actions. Names alone do not establish complete gear geometry, correct pivots, or working kinematics. The candidate has not been integrated or validated in Bevy. Compare its gear, control surfaces, cockpit, and runtime cost with the current F/A-18F before switching.
